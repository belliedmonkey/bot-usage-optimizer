# Weekly memory slimming — disabled routine recipe

**Status: DISABLED by default.** Shipping this file does not create a live schedule. Enabling a schedule and authorizing memory deletion are **separate** owner choices. Template import alone authorizes neither.

## Suggested schedule (only after opt-in)

- Cadence: weekly
- Local time: Monday **09:00** in the adopting owner’s **confirmed** timezone
- Flexibility: ±15 minutes is fine
- Before enabling: confirm timezone/cadence; check for an equivalent routine elsewhere to avoid double runs; do not pause another seat without permission

## Mode

- Default when first enabled: **review-only** (propose candidates; change nothing)
- Write-back requires a **separate** explicit permission naming which memory scopes and reversible edits are allowed, plus a recoverable snapshot/change log before edits and verification after
- Unchanged scheduled runs with no new actionable proposal: **end silently** (quiet)

## Prompt intent

Review accessible memory and durable rules using `usage-memory-slimming`. Keep durable preferences, work principles and active core tasks. Identify proven completed/expired temporary entries, exact duplicates and clearly superseded rules. Stay review-only unless the owner separately authorized scoped write-back; in write-back mode preserve recovery evidence and verify changes. Prepare an at-most-15-line handoff at the agreed notes destination without overwriting unrelated content. Never infer savings or clear uncertain conflicts. Do not change other seats or create new monitoring jobs.

Deliver actionable proposals or a verified change notice only to the owner in this bot's chat; if nothing materially changed and there is no new actionable proposal, end silently.

## Do not

- Auto-install this schedule from a skill load or Marketplace import
- Treat this as usage-dashboard polling (it is optional memory maintenance)
- Delete memories, rewrite security/consent rules, or touch other seats without scoped authorization
