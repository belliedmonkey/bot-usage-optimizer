# Optional memory slimming

This is maintenance, not a usage waste tripwire. Keep useful durable facts while removing proven temporary clutter. Fewer stored words do not by themselves prove lower billed usage; never promise savings without measurement.

## Opt-in
- Ship as a skill and a disabled routine recipe, not an active schedule. Enabling a schedule and authorizing memory deletion are separate choices.
- Offer weekly Monday around 09:00 in the adopting owner's timezone (flexible ±15 minutes) as a suggested starting point. Confirm timezone and cadence when enabling. Check for an existing equivalent routine across accessible scopes to avoid double runs; do not pause another seat without permission.
- Default mode is review-only. For write-back, obtain explicit permission defining which memory scopes and reversible edits are allowed. A template import or agreement to add the capability does not authorize deleting adopter memory.

## Bounded review
1. Read persistent memory and durable rules through the host's supported memory tools. Start with the current visible set and targeted retrieval, not full conversation reloading. If exhaustive enumeration is unavailable, state that the review is partial; do not claim all entries were listed. Never inspect an app's private databases.
2. Categorize: retain durable preferences, working principles and active core tasks; propose removing completed temporary tasks, conclusively expired instructions and exact duplicates. A past deadline alone does not prove a task is completed. Preserve provenance and explicit user decisions.
3. Resolve conflicts only when an explicit later user decision clearly supersedes an earlier one. Ambiguous conflicts are review questions, not automatic deletions. Do not rewrite system/security instructions, consent, credentials, other seats' memories or unrelated skills/routines. Never copy secrets into a summary or backup.
4. Produce a compact candidate set with original entry, reason and replacement if needed. Default review-only: report the proposed edits; change nothing.
5. In explicitly authorized write-back mode, preserve a recoverable snapshot/change log using supported export/storage before editing. If that is unavailable, remain review-only. Save and verify retained/replacement facts first, then remove only exact approved/scope-authorized entries using supported tools. Re-read to verify. Stop on uncertain outcomes; report partial changes honestly.
6. Create a handoff summary of at most 15 lines covering durable working rules, active tasks and unresolved decisions. Save to the agreed notes destination (suggest notes.md); do not overwrite unrelated existing content. A file summary is not a substitute for actual memory write-back. If no destination is agreed, return the summary without inventing a saved file.

## Report
No substantive change and no new actionable proposal: remain silent for scheduled runs. With changes, send one short notice with verified removed/retained counts, distinguishing reviewed subset from total memory. With proposals only, label them pending approval, not completed. Mention missing access or verification once when actionable, not on every identical run.

## Optional routine recipe (disabled by default)
Suggested schedule: Monday 09:00 in the adopter's confirmed local timezone, flexible ±15 minutes. Do not install this schedule merely by loading the skill.

Prompt intent:
Review accessible memory and durable rules using usage-memory-slimming. Keep durable preferences, work principles and active core tasks. Identify proven completed/expired temporary entries, exact duplicates and clearly superseded rules. Stay review-only unless the owner separately authorized scoped write-back; in write-back mode preserve recovery evidence and verify changes. Prepare an at-most-15-line handoff at the agreed notes destination without overwriting unrelated content. Never infer savings or clear uncertain conflicts. Do not change other seats or create new monitoring jobs.
Deliver actionable proposals or a verified change notice only to the owner in this bot's chat; if nothing materially changed and there is no new actionable proposal, end silently.
